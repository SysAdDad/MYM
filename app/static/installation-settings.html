Make Your Mark by SysAdDad

External sign-in requires HTTPS and COOKIE_SECURE=true in the deployment configuration.

Your local recovery administrator remains available. New external accounts start as editors. Change roles in Admin settings.

Organization branding

A small Make Your Mark by SysAdDad credit stays visible. Clear the organization name and logo to restore the default branding.

OpenID Connect

Assign access to this application in your identity provider before enabling automatic provisioning. OIDC identity is matched by issuer and subject, independently of local usernames. Changing issuers creates a separate identity.

LDAP / Active Directory

LDAP example (uid={username}). Active Directory example (&(objectClass=user)(sAMAccountName={username})). Restrict the search base or filter to authorized users.

The service account searches for the user, then the app verifies that user’s password with a separate encrypted bind. Passwords entered during directory login are never saved. Use a service account with read-only directory access.
